# Git Execution \& GitHub Sync Rules

* Execute all Git operations (status, diff, add, commit, push) exclusively via raw terminal CLI commands (`git add`, `git commit`, `git push`).
* Do not call high-level sidecar tools or IDE extension GUI actions when committing or pushing top graphs and per-category graphs to GitHub.
* Never pause for interactive confirmation or launch GUI approval popups when updating, committing, or pushing graph files.
